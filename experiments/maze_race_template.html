Three architectures, and no architecture at all

Each agent sees only five cells by five, so nearly all of the maze is dark to it. Everything it knows about the walls beyond that window it has to remember. What you are watching is not the maze — it is each entrant’s own map, read straight out of whatever it is holding, and it is the only map it is allowed to steer by.

The fourth entrant has nothing to hold. “Raw pixels” has no memory, no state and no parameters: at every step it reads a wall map out of the frame in front of it and forgets. It is here because it is the control — and because a control that beats the models is much harder to look past when it is racing beside them than when it is a number in a caption.

Honest about the division of labour: the entrant supplies the map, and a breadth-first search picks the next step across cells that map calls open. Every agent gets the identical planner, so a difference in exits is a difference in the remembered map and nothing else. Exits reached is the noisier of the two numbers — the wall-decode column is what the benchmark actually settles, and this is what makes the settling watchable.

Why this is the right way round: the maze asks for the walls the agent cannot currently see. Raw pixels should be helpless there, and the gap between each model and the grey board is the only part of the score that is about memory at all. Where a model finishes below it, the honest reading is not that the model is bad at mazes — it is that the model is holding less than the picture already contains.
