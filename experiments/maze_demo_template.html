Recursive Predictive Dynamical Units · experiment 9

A mesh that has never seen the maze, finding its way out of it

The agent only ever sees five cells by five, so nearly all of the maze is dark to it. Everything it knows about the walls beyond that window it has to remember. The right-hand board is not the maze — it is the map read straight out of the mesh’s internal state, and it is the only map the agent is allowed to steer by.

Honest about the division of labour: the mesh supplies the map, and a breadth-first search picks the next step across cells the map calls open. The agent is told which direction the exit lies in, the way an animal following a scent would be — what it is not told is where the walls are. Steering by this remembered map reaches the exit 38 times in 900 steps, against roughly 6 for the same agent wandering at random.
